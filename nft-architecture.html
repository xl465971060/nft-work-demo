NFT Marketplace 项目架构

前端技术栈

  • • React 18.1 + Create React App 5.0.1
  • • react-router-dom 6 (4 个业务路由)
  • • Tailwind CSS 3 + PostCSS 8
  • • ethers.js 5.6 + MetaMask (EIP-1193)
  • • axios 调 Pinata / IPFS 网关

合约与工具链

  • • Solidity 0.8.26 (单合约 ERC-721 市场)
  • • OpenZeppelin 4.7 (ERC721URIStorage/Ownable)
  • • Hardhat 2.22 + Waffle + ethers 5.6
  • • solidity-coverage 覆盖率
  • • 测试：正常/异常/辅助 3 组用例
